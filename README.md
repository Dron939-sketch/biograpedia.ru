# Портал Биографий (Biogr)

Веб-портал для создания, хранения и просмотра биографий известных личностей.

## Описание

Biogr - это современный интерактивный портал, посвященный биографиям выдающихся людей. Проект предоставляет удобный интерфейс для:
- 📚 Изучения биографий известных личностей
- 🎯 Поиска информации по категориям и периодам
- 📝 Добавления новых биографий (для администраторов)
- 🔗 Навигации между связанными личностями

## Планируемые Функции

- [ ] Каталог биографий с поиском и фильтрацией
- [ ] Профили личностей с подробной информацией
- [ ] Временная шкала достижений
- [ ] Категоризация по областям деятельности
- [ ] Система комментариев и рейтингов
- [ ] Управление контентом для администраторов
- [ ] Темная и светлая тема оформления
- [ ] Оптимизация для мобильных устройств

## Как Начать

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lisa-cyber1/Biogr.git
   cd Biogr
   ```

2. Установите зависимости (при наличии):
   ```bash
   npm install
   ```

3. Запустите проект:
   ```bash
   npm start
   ```
