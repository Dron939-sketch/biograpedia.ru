# Биографедия

Биографический портал нового поколения. Точные факты, хронология жизни, связи между людьми и эпохами. Без рекламы и поп-апов.

## Что внутри

- **32 структурированные биографии** в `data/people.json` — писатели, учёные, музыканты, художники, правители, философы, предприниматели.
- **Главная** с виджетом «В этот день», подборкой редакции, цитатой дня и категориями.
- **Каталог** с фасетными фильтрами по категории, эпохе, стране и поисковому запросу.
- **Страница персоны**: инфобокс, биография, цитата, факты, главные работы, хронология, связи с другими людьми, современники.
- **Сравнение двух персон** бок о бок с анализом пересечений — фича, которой нет у конкурентов.
- **Тёмная / светлая тема** с системным определением и переключателем.
- **PWA-манифест**, JSON-LD `Person`, Open Graph, sitemap, robots.txt — для SEO и установки.

## Отдельный сервис: реестр HR

Под доменом работает второй сервис — `/blacklist/` — реестр HR-обращений работодателей. **Это не часть биографического портала.** Тематика, аудитория и редполитика — разные.

Сервис построен с правовыми предохранителями:

- Верификация работодателя по ИНН (заглушка, требуется бэкенд).
- Публикация только инициалов сотрудника; полные ФИО видны сторонам после авторизации.
- Биометрия (фото лица) **не публикуется**.
- Обязательная ручная модерация перед публикацией.
- Право ответа упомянутого лица + досудебное обращение об удалении.
- Все обязательные согласия в форме подачи.

Без полноценного бэкенда сервис работает в демо-режиме: новые обращения сохраняются в `localStorage` пользователя.

## Технологии

- Статический HTML + CSS + Vanilla JS. Никакого билда.
- Данные в JSON: `data/people.json`, `data/reports.json`.
- Шрифты: Inter (sans), Lora (serif).
- Хостинг: любой статический CDN, GitHub Pages, Vercel, Netlify.

## Локальный запуск

```bash
python3 -m http.server 8080
# или
npx serve .
```

Открыть http://localhost:8080

## Как добавить биографию

Добавьте объект в `data/people.json` → `people[]`. Минимальный набор полей:

```json
{
  "slug": "unique-id",
  "name": "Полное Имя",
  "shortName": "Короткое",
  "category": "writers",
  "era": "20th",
  "country": "Россия",
  "city": "Москва",
  "birth": "1900-01-01",
  "death": "1980-01-01",
  "tagline": "Краткое описание в одну строку.",
  "tags": ["тег1", "тег2"],
  "bio": ["Абзац 1.", "Абзац 2."],
  "facts": ["Факт 1", "Факт 2"],
  "timeline": [{ "year": 1900, "event": "Родился" }],
  "works": ["Произведение 1"],
  "relations": [{ "slug": "other-person", "type": "friend", "label": "Друг" }]
}
```

И добавьте URL в `sitemap.xml`.
