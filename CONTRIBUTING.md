# Как добавить биографию

Биографедия — открытый проект. Любая правка и любая новая персона приходят через pull request в этот репозиторий.

## Добавить персону

1. Откройте `data/people.json`.
2. Добавьте новый объект в массив `people`.
3. Слаг (`slug`) — латиницей, через дефис, уникальный в пределах файла.
4. Заполните обязательные поля и хотя бы один из необязательных блоков (факты, хронология, главные работы).

Минимальный шаблон:

```json
{
  "slug": "ivanov",
  "name": "Иван Иванович Иванов",
  "shortName": "Иван Иванов",
  "category": "writers",
  "era": "20th",
  "country": "Россия",
  "city": "Москва",
  "birth": "1900-01-01",
  "death": "1980-01-01",
  "tagline": "Одна строка о том, чем человек важен.",
  "tags": ["писатель", "редактор"],
  "quote": "Любимая цитата с проверяемым источником.",
  "bio": [
    "Абзац 1.",
    "Абзац 2."
  ],
  "facts": ["Факт 1.", "Факт 2."],
  "timeline": [
    { "year": 1900, "event": "Родился в Москве." },
    { "year": 1925, "event": "Опубликовал первую книгу." }
  ],
  "works": ["Главная работа", "Вторая работа"],
  "relations": [
    { "slug": "other-person", "type": "friend", "label": "Дружили" }
  ]
}
```

После добавления — впишите URL новой страницы в `sitemap.xml` (опционально).

## Категории и эпохи

Используйте только существующие `id` из массивов `categories` и `eras` в начале файла. Если нужна новая категория — обсудите в issue до добавления.

## Что обязательно проверить

- Все даты — в ISO-формате `YYYY-MM-DD`.
- Цитаты — с подтверждаемым источником, не «народный фольклор».
- Хронология — события в правильном порядке.
- Слаг не пересекается с уже существующим.
- JSON остаётся валидным: `python3 -c "import json; json.load(open('data/people.json'))"`.

## Правки в существующих биографиях

- Опечатки и фактические ошибки — приветствуются.
- Стилистические и редакторские правки — приветствуются, если делают текст яснее.
- Любые добавления, требующие проверки источника, — желательно с пометкой в описании PR откуда сведения.

## Что не принимаем

- Биографии живых людей без согласия (за исключением широко публичных деятелей).
- Тексты, скопированные с других сайтов без переработки.
- Оценочные суждения без атрибуции.
- Слухи и непроверенные истории.

## Локальный запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/
```

После изменений в `data/people.json` достаточно перезагрузить страницу.
